> 本书示例目前使用 `scoop 0.0.0-dev.20261110` 验证。

## 这本书写给谁

本书面向有 Kotlin 经验的应用开发者。你不需要了解编译器、类型理论或垃圾回收的实现，只要写过 Kotlin 程序，就能顺着本书学会用 Scoop 写出完整的原生应用。

Scoop 的语法以 Kotlin 为基础，所以本书不会从“什么是变量”讲起，而是把篇幅花在 Scoop 与 Kotlin **不同**的地方：真正的值类型、模式匹配、没有 `null` 的 `Option`、默认的可见性规则、协程的进入方式等。相同的地方，书中一般一笔带过；看起来相同、实际行为不同的地方，会专门指出来。

本书目前不涉及图形界面（`scoop.window`、`scoop.ui` 等库），这部分内容另行编写。

## 怎样阅读

- **第一部分（起步）**：Scoop 是什么、怎样安装和运行程序。
- **第二部分（语言基础）**：变量与数值、字符串、控制流、函数、lambda。大部分语法你会觉得眼熟，重点看「从 Kotlin 过来」栏指出的差异。
- **第三部分（值类型与模式匹配）**：struct、enum、tuple、解构、`when` 模式匹配和 `Option`。这是 Scoop 最有特色的部分，也是和 Kotlin 差别最大的部分。
- 第一至第三部分是基础，建议按顺序读。
- **第四至第八部分**：类与泛型、错误处理与资源、集合与标准库、并发与异步、工程化。可以按需要选读。
- **第九部分**是常用库的实战，**第十部分**讲与 C 代码互操作，只写纯应用的读者可以跳过第十部分。
- **第十一部分**是综合项目，**附录**提供 Kotlin 速查表、常见编译错误、命令速查等，适合随手查阅。

书中有两类提示框：

> **从 Kotlin 过来**
>
> 对比 Kotlin 的写法，指出直接照搬时会遇到的问题。

> **深入一点**
>
> 介绍背后的机制。跳过这些内容不影响理解正文。

## 示例

书中的每个示例都是一个完整的程序，并附有它的实际输出；演示错误写法的示例则附上编译器的报错原文。这些示例都用上面注明版本的工具链编译、运行过。安装工具链之后，把示例保存为 `.scoop` 文件就能运行：

```sh
scoop run hello.scoop --release
```

第 2 章会详细介绍安装与运行。
