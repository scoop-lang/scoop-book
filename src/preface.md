# 前言

> **关于本书版本**：Scoop 语言仍在开发中，尚未正式发布，语法、标准库 API 和工具命令都可能变化。本书是持续更新的在线书，会随语言演进修订；如果书中内容与你手上的工具链行为不一致，以工具链为准，也欢迎反馈。
>
> 本书示例目前使用 `scoop 0.0.0-native-desktop.20261107` 验证。

## 这本书写给谁

本书面向有 Kotlin 经验的开发者。你不需要了解编译器、类型理论或垃圾回收的实现，只要写过 Kotlin 程序，就能顺着本书学会用 Scoop 写出完整的原生应用。

Scoop 的语法以 Kotlin 为基础，所以本书不会从“什么是变量”讲起，而是把篇幅花在 Scoop 与 Kotlin **不同**的地方：真正的值类型、模式匹配、没有 `null` 的 `Option`、默认的可见性规则、协程的进入方式等。

## 怎样阅读

- 第一至第三部分是基础，建议按顺序读。第三部分（值类型与模式匹配）是 Scoop 最有特色的部分。
- 第四至第八部分可以按需要选读。
- 第九部分是常用库的实战，第十部分讲与 C 代码互操作，只写纯应用的读者可以跳过第十部分。

书中有两类提示框：

> **从 Kotlin 过来**
>
> 对比 Kotlin 的写法，指出直接照搬时会遇到的问题。

> **深入一点**
>
> 介绍背后的机制。跳过这些内容不影响理解正文。

## 运行示例

书中的完整示例都可以直接运行。安装工具链之后，把示例保存为 `.scoop` 文件并执行：

```sh
scoop run hello.scoop --release
```

第 2 章会详细介绍安装与运行。
